# Roadmap

Completed work and planned improvements for MSW Dev Tool. Priorities may change with
[feedback](https://github.com/nayounsang/msw-dev-tool/issues).


## Separation of packages ✅

Packages are split into `@msw-dev-tool/core` and `@msw-dev-tool/react`.
Node support lives in `@msw-dev-tool/core/node`, with `@msw-dev-tool/node-cli` for AI programmatic control.

## More flexible response customization ✅

HTTP handlers and WebSocket listeners support runtime behaviors, custom response data, and temporary handlers.

## GraphQL support

GraphQL handler discovery and runtime scenario control are planned.

## Global mock controls ✅

The toolbar **Mock Enable** switch bypasses HTTP and WebSocket mocks while preserving the
individual behavior and enable settings.
