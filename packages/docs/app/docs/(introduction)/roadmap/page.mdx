# Roadmap

Completed work and planned improvements for MSW Dev Tool.

There is no priority for this yet, but I plan to prioritize it given your feedback.
[Please give me feedback!](https://github.com/nayounsang/msw-dev-tool/issues)

1. **Separation of packages** ✅

Packages are split into `@msw-dev-tool/core` and `@msw-dev-tool/react`.
Node support lives in `@msw-dev-tool/core/node`, with `@msw-dev-tool/node-cli` for AI programmatic control.

2. **More flexible response customization** ✅

HTTP handlers support runtime behaviors, custom response data, and temporary handlers. More flexible response customization is also needed for WebSocket scenarios.

3. **GraphQL support**

GraphQL handler discovery and runtime scenario control are planned.

4. **Disable full mocking**

With the addition of mock disable to behavior, the disable logic utilizing checkboxes is gone.
I plan to keep this, and make it possible to disable the mock entirely with a switch-like ui.
